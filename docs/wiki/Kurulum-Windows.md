# Kurulum (Windows)

1. [Releases](https://github.com/omerustundag58/dpi-vpn/releases/latest) sayfasından
   `DPI-VPN-Turkiye.exe` indir, çalıştır. (SmartScreen çıkarsa "Yine de çalıştır".)
2. **BAŞLAT**'a bas.
3. Firefox → Ayarlar → Ağ → Elle yapılandır → yalnızca **HTTPS Proxy**:
   `127.0.0.1`, port `8888`.

Discord/Roblox uygulaması için: **Sistem Proxy: AÇIK** + **DNS Modu: AÇIK**
(UAC onayı ister). Site yine açılmazsa **QUIC Engelle**'ye bas.
