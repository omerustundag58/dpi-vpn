# SSS

**Site açılmıyor, ne yapayım?**
Önce Hızlı mod → Dengeli → Parçala sırayla dene. Olmazsa QUIC Engelle'yi aç.

**"DNS zehirli" diyor.**
DNS Modu'nu kapatıp tekrar aç (UAC onayla). Hâlâ diyorsa ISS'n DNS'i
şeffaf kesiyordur — Sistem Proxy + QUIC Engelle ile devam et.

**İnternet yavaşladı.**
Durdurunca sistem proxy'si otomatik kapanır. Hâlâ yavaşsa DNS Modu'nu
kapat (1.1.1.1 bazenISS içi trafiği yurtdışına taşır).

**Windows "bilinmeyen yayımcı" diyor.**
 İmzasız exe'de normal: Ek bilgi → Yine de çalıştır.

**Ücretsiz mi? Kayıt var mı?**
Evet ücretsiz, kayıt/hesap yok. Kod herkese açık (GPL-3.0).

**VPN açıkken bankaya girebilir miyim?**
gov.tr/com.tr siteleri otomatik tünelsiz geçer, sorun olmaz.
