# Kurulum (Android)

1. [Releases](https://github.com/omerustundag58/dpi-vpn/releases/latest) sayfasından
   `dpi-vpn-android.apk` indir, kur (bilinmeyen kaynak izni ister).
2. Uygulamayı aç, profili seç (ISS'ne göre), **BAŞLAT**'a bas.
3. VPN izni penceresinde **Tamam** de. Hepsi bu.

İpuçları: yalnızca seçtiğin uygulamalar geçsin istersen **Uygulama Seç**,
DNS zehirleniyorsa **Özel DNS** anahtarı, video/ses takılırsa **QUIC engelle**
açık kalsın.
